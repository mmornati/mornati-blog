## Overview

After a week [testing](/2013/12/11/hurricane-rom-for-galaxy-note-2-make-it-like-the-note-3/) the Hurricane v6 ROM on my Galaxy Note 2, I decided to give the official Samsung 4.3 ROM for my phablet a try, which had meanwhile been released.
With the custom Hurricane ROM, even if it worked well, I found some annoying bugs that led me to change the ROM once again, for the official one.

## Issues

Here a short list of things I didn't like on the custom Hurricane ROM:

- **Application crashes**: sometimes applications crash without any real reason. I have no memory problem, I can't see anything on the logcat, but sometimes nothing worked. To resolve this problem, the only solution I found was to reboot the phone.
- **Google account lost**: occasionally, and inexplicably, the phone lost the connection with the Google account. To correctly use it again it was necessary to enter the credentials and wait for the complete synchronization (contacts, mail, Google+, ...). Lot of time lost for nothing!
- **Phone call crashes**: I think it is linked with the application crashes, but two times (in a week) the phone application crashed during a phone call. Not exactly a good thing for a device you use mainly to make phone calls ;)

As you can see there were not many problems on the ROM, but I didn't like these little things. Anyway, if you want to have Note 3 functions (such as Air Command) you should use a custom ROM, like this one, because Samsung did not integrate all Note 3 functions in the official ROM. In this case, the Hurricane ROM is maybe the best one for your Note 2.
