## Introduction

Every time I installed a new version of Fedora (I used to do a fresh installation to prevent any possible package errors/compatibility) I spent a lot of time reconfiguring my installation with the usual tweaks: installing additional repositories, configuring flash player (hoping it will die in the future), installing Java, ..., ...

![FedoraUtils](/images/fedora-utils-tweaks-for-your-preferred-distro/00-screenshot_dufjlt.png)

## What is Fedora Utils?

This time, while surfing the internet, I discovered [Fedora Utils](http://fedorautils.sourceforge.net/), an incredible project (simple but useful) that does all this configuration for you. You just need to select what you want and it will install everything for you. I know, it's not too difficult to create a simple bash script to do the same thing, but I'm too lazy to spend time configuring my home desktop :)

## Conclusion

Test it and enjoy.
