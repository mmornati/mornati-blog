Anytime I installed a new version of Fedora (I used to make fresh installation to prevent any possible package errors/compatibility) I spent lot of my time reconfiguring my installation with the stuffs: installing additional repository, configuring flash player (hoping it will die in the future), install java, ..., ...

![FedoraUtils](/images/fedora-utils-tweaks-for-your-preferred-distro/00-screenshot_dufjlt.png)

This time I discovered surfing on internet <a href="http://fedorautils.sourceforge.net/">Fedora Utils</a>, and incredible project (simple but useful) that make all this configuration for you. You have just to select what you want and it will install everything for you. I know, it's not to difficult to create a simple bash to do the same thing, but I'm too lazy to lose time configuring my home desktop :)

Test it and enjoy.
