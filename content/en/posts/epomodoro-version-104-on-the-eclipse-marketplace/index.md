I just released the new ePomodoro version.

## What's New

- Minor bug fixes
- Message Receiver Listener activated also when Team Status view is not active/visible
- Restyled user message box (to send a message to a user you can select it on the TeamStatus table and then choose *Send Message* using the right-click context menu)

## Installation

You can find it on the [ePomodoro update site](http://repos.mornati.net/eclipse) (I noticed that you can't browse the repository if you are using Google Chrome or Safari, don't know why), or download it from the [Google Code ePomodoro page](http://code.google.com/p/e-pomodoro/downloads/list).

And, starting today, you can find it on the [Eclipse Marketplace](http://marketplace.eclipse.org/content/epomodoro) too (I think you should use the update site even if you go through the marketplace).

Sources are available on [GitHub](https://github.com/mmornati/epomodoro) and [Google Code](http://code.google.com/p/e-pomodoro/source/checkout).
