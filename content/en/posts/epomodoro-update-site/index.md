Since today you can install [ePomodoro](http://code.google.com/p/e-pomodoro/) directly using the provided update site! And naturally update it using the Eclipse function *Check for Update*.

[![ePomodoro Update Site](/images/epomodoro-update-site/00-ePomodoro7_xvrnat.png)](https://res.cloudinary.com/blog-mornati-net/image/upload/v1391641361/ePomodoro7_xvrnat.png)

## Update Site Installation

You can add this Update Site: [http://repos.mornati.net/eclipse/](http://repos.mornati.net/eclipse/) and select ePomodoro.
