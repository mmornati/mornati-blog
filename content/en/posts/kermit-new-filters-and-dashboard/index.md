## Tree Filters

[KermIT](http://www.kermit.fr) development is going ahead, adding new functions every day. Today two new videos showing Tree Filters and Persistent Dashboard.

A problem with big datacenters in the previous KermIT version was all widgets with classes served inside (for example, the puppet classes widget). If you wanted to reach a particular class or server you had to look for it by hand (search in any folder to find your server). Now you can simply search the resource you need (folder or server name) and you will be pointed to matching resources.

[video src="http://www.mornati.net/video_kermit/video/KermIT%20-%20Filters%20in%20tree%20views.mp4" width="100%"]

## Persistent Dashboards

Even if you could move or change dashboard widgets, all modifications were not persisted in the previous KermIT version; a simple page refresh restored the default settings.
Now any user can personalize their dashboard by changing widget position, colors, titles, and more — and all changes will be persisted (each user has a different dashboard). Cookies are required to allow this new function.

[video src="http://www.mornati.net/video_kermit/video/KermIT%20-%20Persistent%20Dashboard%20(per%20user).mp4" width="100%"]

Stay tuned because we have more interesting and useful functions coming... Do you want to create a new server in a click? You should use KermIT ;)
