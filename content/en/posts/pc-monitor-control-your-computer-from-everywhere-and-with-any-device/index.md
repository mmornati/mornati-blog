## Introduction

Some weeks ago I found [PC Monitor](http://mobilepcmonitor.com/), a cool new way to control your Linux and Windows computer. On the product website, you'll find a server program for Linux and Windows (both 32-bit and 64-bit) and client apps for Android, Windows Phone, and iOS devices.

## Server Setup

I tested the Linux server version for a few days, and it's really easy to install, configure, and start. It's a Java program, so you just need the JDK and a service file to start the server.

## Mobile Client

On the iOS client, you get real-time information about your PCs, including system metrics, running processes, and more.
