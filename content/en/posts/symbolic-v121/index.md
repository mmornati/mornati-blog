I'm happy to announce you that <a href="http://www.opensymbolic.org/" target="_blank"><span style="font-weight: bold;">Symbolic 1.2.1</span></a> is finally sort out!!<br /><br /><a onblur="try {parent.deselectBloggerImageGracefully();} catch(e) {}" href="http://www.opensymbolic.org/images/screenshots/home-admin2.png" target="_blank">![](http://www.opensymbolic.org/images/screenshots/home-admin2.png)</a>In this minor release we haven't add any kind of new features, but we worked a lot to make the application stable and stronger.<br /><br />The new features added are listed below:<br />- Update graphical icons<br />- Reviewed running operations window<br />- Solved bugs during script execution<br />- Moved engine to use Func 0.23+<br />- Added some basic operations<br />- Create a symbolic-setup scripts that help you to setup acls on func folders<br />- Solved some bugs in VirtualManager execution<br />- Create a Makefile to simplify the build process<br /><br />To make a correct installation of the application you can follow <a href="http://www.opensymbolic.org/docs/v1.2.1/html/Symbolic-Tutorial.html">this tutorial</a>.<br /><br />Enjoy!<br />Any kind of comment is welcome!
