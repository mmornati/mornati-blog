I'm happy to announce that [Symbolic 1.2.1](http://www.opensymbolic.org/) has been released!

This minor release focuses on stability and robustness rather than new features. We've worked hard to make the application more stable and reliable.

## What's New

The new features and improvements include:

- Updated graphical icons
- Reviewed running operations window
- Fixed bugs during script execution
- Moved engine to use Func 0.23+
- Added some basic operations
- Created symbolic-setup scripts that help you to set up ACLs on func folders
- Fixed some bugs in VirtualManager execution
- Created a Makefile to simplify the build process

## Installation

For installation instructions, please refer to the official documentation.
