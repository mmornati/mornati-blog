## World: Infrastructure Schematic

Dark mode reads as a night terminal/schematic; light mode reads as blueprint paper pinned above a desk. Both are drawn from one blueprint-blue neutral ramp rather than a naive invert, so they feel like two real artifacts of the same discipline, not a light theme and its negative. Content renders as labeled, connected nodes — post cards, category chips, and TOC entries all borrow the vocabulary of a diagram (node markers, port labels, signal dots) rather than a generic blog-template card grid. Chosen via the skill's direction round (seed key `d0c81b63`, candidate 6 of 7 self-derived audience-grounded systems — Home Assistant dashboard, Unix terminal, rack hardware, solar meter LCD, GPS trail-watch, network topology diagram [chosen], maker breadboard notebook), raised with disciplines borrowed from three dealt catalog challengers (magnitude-as-size encoding from a star-atlas challenger, status-by-shape-not-color from a film-editing-bench challenger, single-grotesque grid discipline from a design-annual challenger).

Full contract: `.impeccable/surfaces/localhost.md`.

## Color

Color strategy: **Committed** — one saturated accent (copper/amber) carries the site's signal color across both modes; a secondary cyan carries a smaller, deliberate share (category badges, surplus/export data, TOC/code-block framing).

Custom Blowfish scheme at `assets/css/schemes/schematic.css`, activated via `colorScheme = "schematic"` in `config/_default/params.toml`. One neutral ramp drives both appearances (light end = blueprint paper, dark end = night terminal); Blowfish's existing `dark:` Tailwind variants pick the light/dark end of the same ramp, so the light/dark switch itself needed no new logic.

| Role | Light (50→300 typical) | Dark (400→900 typical) |
|---|---|---|
| Neutral (ground/ink) | `#eef3f8` ground → `#2d394f` ink | `#0b0e14` ground → `#e3e9f0` ink |
| Primary — copper/amber signal | `#c46c1a` (600: `#a35712`) | `#e08a2d` (400) |
| Secondary — cyan trace | `#1b9cb3` (600: `#128096`) | `#33b8ce` (400) |

The standalone `static/solar-analysis/index.html` page (outside Hugo/Blowfish's build) reimplements the same ramp as local CSS custom properties under `:root` / `html.dark`, and shares the site's `localStorage("appearance")` key so the light/dark preference is a single, site-wide setting.

## Typography

- **Archivo** — display, headings, UI chrome, labels. Loaded via Google Fonts in `layouts/partials/extend-head.html`; wired in as the global `--font-sans` (`assets/css/custom.css`), so it drives every heading and UI element by default.
- **Source Serif 4** — long-form article body copy only (`.prose :where(p, li, blockquote, dd)`), for reading comfort across the blog's core content.
- **JetBrains Mono** — code blocks (`--font-mono`), category/tag "port label" badges, and the solar-analysis page's data figures.

## Components

- **Post cards** (`.article-link--card` in `assets/css/custom.css`): sharp corners (no rounding — a deliberate departure from the theme's default `rounded-lg`, since a blueprint/schematic world doesn't round its corners), a 2px copper top edge, and a small corner "solder pad" dot. Hover lifts and deepens the shadow.
- **Category/tag chips** (`layouts/partials/badge.html` → `.schematic-badge`): monospace, uppercase, tracked, with a small leading signal dot. Categories render in the cyan/secondary variant (`showCategoriesInSecondaryColor = true`), tags in copper/primary, so the two taxonomies stay visually distinct.
- **Article headings** (`h2`/`h3` inside `.prose`): a small copper "node marker" square precedes the heading text — a junction dot, not a rule.
- **Table of contents**: the smart/scroll-synced TOC (`smartTOC = true`) highlights the current section in copper with a small leading dot — "a locked signal."
- **Code blocks** (`.highlight-wrapper`): a plain hairline neutral frame, sharp corners — kept deliberately quiet (an earlier copper/cyan accent-border treatment was removed after the design detector correctly flagged it as a recognizable "AI slop" tell).
- **Homepage** (`layouts/partials/home/grid.html`): the author avatar carries a small status dot (`.schematic-avatar`), and the divider between the author block and the post list is a measured "schematic rule" (`.schematic-rule`) with endpoint dots instead of a plain `<hr>`.
- **Categories page** (`layouts/partials/term-link/text.html`): column width widened and label size reduced slightly from the theme default — the switch to the wider Archivo face at the theme's original `text-xl`/quarter-width columns caused long category names to wrap mid-word; fixed as part of this pass.
